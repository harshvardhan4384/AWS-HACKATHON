Frontend Setup

1. cd frontend
2. npm create vite@latest . -- --template react
3. npm install
4. npm run dev
5. npm install react-router-dom @tanstack/react-query axios


Backend Setup 

1. cd Backend
2. npm init -y
3. npm install express cors helmet dotenv zod
4. npm install prisma @prisma/client
5. npm install -D nodemon
6. npx prisma init --datasource-provider postgresql


TO RUN

1. cd frontend/backend
2. npm install
3. npm run dev
